Qui les voit

Dans un ceck, chacun voit seulement ce que son rôle permet : une entreprise ne voit jamais les données d’une autre. En dehors de l’entreprise : seulement l’éditeur de ceck pour l’assistance (voir plus bas) et les prestataires techniques listés ci-dessous. Nous ne vendons pas les données et ne les utilisons pas pour la publicité.

Où elles sont

Dans l’Union européenne : serveur en Finlande (Hetzner), sauvegardes dans l’UE. Les traductions automatiques passent par DeepL (Allemagne). Les données de carte bancaire sont traitées uniquement par Stripe (Irlande) : ceck ne les voit jamais.

Sécurité

Connexion chiffrée (https), mots de passe chiffrés, sauvegarde chaque nuit, chaque entreprise dans une base séparée. En cas de fuite ou de perte de données, nous prévenons les entreprises concernées et, si nécessaire, la CNIL dans les 72 heures.

Accès d’assistance

L’éditeur de ceck n’accède aux données que pour résoudre un problème, corriger un défaut ou protéger le service : l’accès est limité aux données nécessaires, motivé et enregistré. Pour les données de chantier, il a lieu selon les instructions documentées de l’entreprise (art. 28 du RGPD). Ces données restent confidentielles.
