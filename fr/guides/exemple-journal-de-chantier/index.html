Journal de chantier : exemple concret d’une journée sur le chantier

Comment documenter une journée de travail sur un chantier ?

Voici un exemple concret de registre interne, à partir d’une situation qui peut arriver pendant la rénovation d’un appartement.

Exemple de journée de travail

Chantier : rénovation d’un appartement.

Personnel présent : quatre ouvriers.

Heures travaillées : neuf heures par ouvrier.

Total main-d’œuvre : 36 heures.

Travaux réalisés :

  • pose des plaques de plâtre dans le séjour ;
  • préparation des murs de la chambre ;
  • pose de l’ossature du faux plafond.

Matériel reçu :

  • 20 plaques de plâtre ;
  • 15 rails et montants métalliques ;
  • deux boîtes de vis.

Problèmes constatés :

  • une prise électrique n’est pas à l’endroit prévu ;
  • il manque des plaques pour finir le faux plafond.

Prévu pour demain :

  • finir les cloisons ;
  • vérifier l’emplacement de la prise ;
  • commander le matériel manquant.

Pourquoi ces informations sont-elles importantes ?

Si le travail s’arrête le lendemain, vous vérifiez tout de suite si le problème avait déjà été signalé.

Si le client demande des explications sur les heures, vous consultez les tâches notées.

Si vous devez préparer un chantier semblable, vous avez des informations utiles pour mieux l’organiser.
