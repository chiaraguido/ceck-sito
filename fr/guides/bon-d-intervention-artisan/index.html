Bon d’intervention : comment documenter le travail réalisé chez un client

Un électricien remplace une prise.

Un plombier intervient sur une fuite.

Un menuisier retourne chez le client pour régler une porte.

Ce sont des interventions simples en apparence, mais elles aussi doivent être documentées.

Que doit contenir un bon d’intervention ?

Un document de travail devrait indiquer :

  • les coordonnées du client ;
  • l’adresse de l’intervention ;
  • la date ;
  • le problème signalé ;
  • le travail réalisé ;
  • les heures passées ;
  • le matériel utilisé ;
  • ce qu’il reste éventuellement à faire.

Quand c’est possible, il est utile de garder aussi les photos du problème et du résultat final.

Une photo peut éviter bien des discussions

Imaginez une intervention sur un meuble abîmé.

Avant de commencer, vous photographiez le dégât. Après l’intervention, vous photographiez le résultat.

Si le client vous rappelle quelques semaines plus tard, vous retrouvez plus facilement ce que vous avez fait.

Quand il faut revenir une deuxième fois

On ne peut pas toujours tout régler tout de suite.

Il faut parfois commander une pièce, attendre un autre artisan ou obtenir l’accord du client.

Noter le problème permet de ne pas oublier ce qu’il reste à faire.
